# Quality of Terraria 更好的体验

基于[更好的体验(ImproveGame)](https://github.com/487666123/ImproveGame)的泰拉瑞亚模组。

**移植版本**：适配 TerrariaModder v0.4.1+  
**原版作者**：487666123  
**当前版本**：v1.1.3<br>
**适配游戏版本**：泰拉瑞亚 1.4.5.8+

\---

## 📖 简介

基于 tModLoader 平台热门 MOD [更好的体验(ImproveGame)](https://github.com/487666123/ImproveGame) 移植到 TerrariaModder 平台的版本。提供大量便捷功能，让玩家能够更流畅地享受游戏，而不改变核心玩法。

**核心特性**：

* 🎒 **强大的存储系统**：终极存储面板、100格随身大背包、智能物品整理
* 🔨 **便捷的建造工具**：快速放置、液体魔杖、连锁挖矿、工具加速
* 🗺️ **实用的辅助功能**：结构定位、自动钓鱼、NPC管理、护士快捷治疗
* 📊 **详细的信息面板**：角色属性、DPS测试、刷怪率控制
* 🌐 **联机存储**：普通玩家可用、角色标记独立保存、服务器核验存取

## ⌨️ 默认快捷键

|按键|功能|按键|功能|
|:-:|-|:-:|-|
|**K**|终极存储|**B**|随身大背包|
|**P**|快速放置|**L**|液体魔杖|
|**G**|结构定位与快捷键表|**X**|测试假人与DPS|
|**Y**|角色属性面板|**Z**|自动钓鱼|
|**\[**|刷怪率与世界控制|**H**|快捷护士治疗|
|**N**|城镇NPC回家|**.**|随身猪猪钱罐|

|**\\**|切换工具加速|**Shift**|按住临时强制连锁|

**液体魔杖操作**（需先按 `L` 开启）：

* 按住 **`;`** 吸收液体
* 按住 **`'`** 放置液体

> 💡 \*\*提示\*\*：所有快捷键均可在游戏内的模组配置中自定义。改键后可按 `G` 打开结构定位面板并查看当前快捷键绑定。

## ⚡ 核心功能

<details>
<summary><b>🎒 收纳与物品整理</b></summary>

### 终极存储面板 (K)

* 集中查看已标记箱子中的所有物品
* 自动标记已打开的箱子，支持手动批量标记/取消标记
* 联机标记按“世界＋角色”独立保存，其他玩家增删标记不会影响自己；重新进房或服务器重启后恢复
* 普通玩家也可远程使用自己的标记箱子，无需房主或管理员权限；箱子管理中的“打开”可打开对应原版箱子窗口

* 九大分类浏览：全部、武器、防具、饰品、工具、弹药、建筑、药水、家具
* 名称与前缀搜索，支持中文输入
* 左键取整组，右键取一半，拿着物品点击可存入
* 跨箱智能合并与整理：同物品同前缀自动合并，支持多种整理规则

* 独立角色仓库，不占用背包空间
* 支持整组抓取、快速放入、Shift+左键快速取出
* 提供批量存入、取出、整理功能
* 完整显示前缀与物品属性

### 便携收纳增强

* 按 `.` 键快速打开猪猪钱罐
* 中键点击背包中的便携收纳道具直接打开
* 信息配件放在便携收纳中也能生效
* 拾取的金钱自动存入猪猪钱罐

### 重铸词缀记录

* 记录重铸历史词缀
* 右键点击重铸槽可回到之前的词缀
* 避免误操作丢失心仪词缀

## 🌐 联机支持

房主／服务器和所有玩家安装相同修复版后，可使用联机功能。

### 服务器部署

* 将发布包中的 `quality-of-terraria` 文件夹放入 `TerrariaModder/mods/`，更新时覆盖同名文件
* 服务器目录中需同时包含 `QualityOfTerraria.dll`、`QualityOfTerraria.Server.bin` 和 `manifest.json`
* 所有玩家也需更新同一份安装包，然后重启游戏及服务器；服务器不会自动替玩家安装模组

### 权限管理

* **刷怪率控制**：仅房主或管理员可提交修改
* **世界特性调整**：仅房主或管理员可修改
* **其他功能**：所有玩家均可独立使用

### 数据同步

* 终极存储标记各角色独立，随身大背包随角色保存；两名玩家可以分别标记同一个世界箱子，箱内实物仍是同一份
* 终极存储读取自己标记且经服务器确认的箱子；锁定、被其他玩家占用的箱子不能操作
* 每个角色拥有独立标记列表，角色在游戏内改名后仍保留。首次升级会复制服务器上旧身份的标记，之后各自增删；旧文件保留
* 房主／服务器与所有玩家都需更新至 v1.1.3；旧客户端不支持新的角色身份握手
* 同一个角色连同 ID 文件复制后的副本属于同一角色，会使用同一份标记；新建角色拥有独立身份

## 💾 存档备份建议

使用本模组时，强烈建议定期备份存档：

1. **角色存档路径**（Windows）：

```
   C:\\Users\\<用户名>\\Documents\\My Games\\Terraria\\Players\\
   ```

2. **世界存档路径**（Windows）：

```
   C:\\Users\\<用户名>\\Documents\\My Games\\Terraria\\Worlds\\
   ```

3. **建议**：

   * 在使用新模组功能前备份一次
   * 定期（如每周）备份重要存档
   * 大型建设或重要战斗前备份
   * 角色存档旁的 `角色文件名.plr.qot-character-id` 保存终极存储角色身份。换电脑或手动移动／重命名存档时，连同此文件一起迁移，并与 `.plr` 文件名保持对应
   * 服务器标记保存在游戏存档目录的 `TerrariaModder/world-data/` 下；迁移服务器时连同世界一起备份。删除角色 ID 或服务器标记文件会使原标记无法对应
