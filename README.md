# Quality of Terraria 更好的体验

让收纳、建造和探索方便一些的 TerrariaModder 模组。当前版本 **v1.1.1**，适用于 **Terraria 1.4.5.8、TerrariaModder 0.4.1**。

## 安装与设置

1. 先安装 TerrariaModder。
2. 把发布包中的 `quality-of-terraria` 文件夹放入游戏目录的 `TerrariaModder/mods/`。
3. 更新模组时替换原文件夹中的同名文件，然后重新启动游戏。
4. 在加载器的模组设置中调整功能开关和快捷键。

联机需要房主／专用服务器和所有玩家安装相同版本的本模组与 TerrariaModder。共享世界设置由房主或服务器管理员控制。

液体魔杖开启后，按住 `;` 吸收液体，按住 `'` 放置液体。改键后，可在结构定位面板查看当前快捷键。

## 收纳物品

### 终极存储

按 `K` 打开。普通箱子打开后会自动加入终极存储，也可以在标题栏的“箱子管理”中手动标记、取消标记或标记附近箱子。

全世界自己标记的箱子都可以远程查看和存取，无需先靠近打开。箱子管理中的“打开”会请求打开该箱子的原版窗口；锁定、被他人占用或已拆除的箱子不能操作。每名玩家的标记单独保存，联机存取、快速堆叠和整理由服务器核验执行，确认后更新物品。

物品可以按分类查看，搜索名称或前缀。点击搜索框旁的“顺序”切换排列方式：默认、种类、稀有度、数量、名称、ID。第一次点击“顺序：默认”会切到“种类”。

| 操作 | 效果 |
| --- | --- |
| 左键点击物品 | 整组取到角色背包 |
| 右键点击物品 | 取一半，至少一件 |
| 拿着物品点击格子 | 存入可操作的标记箱子 |
| 全部存入 | 存入背包中符合当前分类的非收藏物品 |
| 快速堆叠 | 把背包物品补到箱内已有的同类堆叠中 |
| 整理箱子 | 先跨箱合并，再按所选顺序排列各箱 |
| 全部取出 | 取出当前分类和搜索结果中的物品，放不下的留在箱中 |

整理时只合并相同物品且前缀相同的堆叠。不同前缀不会混在一起，不可堆叠的装备仍保持分开；堆叠满后，剩余数量保留。锁定、未标记或被其他玩家占用的箱子不参与整理。

按种类排列时，顺序为武器、防具、饰品、工具、弹药、建筑、药水、家具、其他，同类再按名称排列。默认浏览保持箱子原有顺序；默认整理仍按稀有度排列。

### 随身大背包

按 `B` 打开100格额外仓库。左键抓取、放入或交换整组物品；Shift＋左键取到角色背包。底部有存入、全部取出和整理按钮。

两个存储窗口悬停都显示带前缀的完整名称，图标保留物品的颜色、动画和发光效果。大背包随角色保存。

## 建造与液体

**快速放置**：按 `P` 开启，手持方块、平台或背景墙，左键拖拽范围，松开后铺设，右键取消。使用普通工具或武器前，再按 `P` 关闭。

联机快速放置由服务器检查材料并铺设，单次框选最多4096格，超出时缩小范围后重试。物块放置与工具触及的距离增加量可设为0—30格，默认5格；0不增加。

**快速铺墙**：背包里放好背景墙，按 `O` 填充角色周围没有墙的区域。背包中有多种墙时，使用靠前的一组。快速放置和快速铺墙是否消耗材料，可在模组设置中调整。

**液体魔杖**：按 `L` 依次切换关闭、水、岩浆、微光和蜂蜜模式，吸收后再放置。HUD显示当前储量，已经满的液体格不会重复扣量。

单机液体储量在本次游戏进程中保留，退出世界会关闭工具，退出游戏后清空。联机储量由服务器按玩家记录，限当前服务器世界会话，不与其他玩家共用。

## 探索、钓鱼与战斗辅助

- **自动钓鱼**：按 `Z` 开启。背包里需要有鱼竿、合适的鱼饵，并靠近可钓的液体。正常速度下约每10秒尝试一次，使用手持鱼竿；没有手持时选背包中渔力最高的杆。钓鱼仍受渔力、群落、任务鱼、鱼饵和断线规则影响，不保证每次都有收获，也不能钓微光。
- **渔获收纳**：单机先尝试存入25格内可写的标记箱子，再放入角色背包和大背包；放不下的掉在角色脚下。联机自动钓鱼仍使用客户端原版收获流程，新渔获不直接写入远程箱子；收入背包后可手动存入终极存储。
- **结构定位**：按 `G` 选择以太、地牢、神庙、花苞、剑冢、空岛、金字塔、蜂巢、大理石或花岗岩。扫描时显示进度；联机请求服务器分帧扫描全世界，找到后同步目标附近区块，无需本地预先加载目标瓦片。
- **测试假人**：按 `X` 在鼠标处放置或移除，面板显示实时DPS、平均DPS和累计伤害，右键面板可重置。联机假人由服务器生成，个人DPS只统计自己对自己假人的伤害。
- **角色属性**：按 `Y` 查看攻防、暴击、穿透、移速等属性。
- **快捷治疗与回家**：`H` 按实际缺失生命与可清除负面状态收费；满血但有可清除负面状态仍可治疗，满血且无需清除时提示“生命值已满且无可清除的负面状态，无需治疗”，不扣钱。`N` 召回城镇NPC，`.` 打开猪猪钱罐。
- **刷怪与世界控制**：按 `[` 打开，提供和平模式、多档刷怪倍率和0—100自由拖动滑条，松开后提交设置并保存。联机由房主／管理员调整，权限不足会提示原因。也可切换节日和部分世界特性，切换不会重新生成已有地形。
- **气象控制**：按 `U` 切换下雨和放晴。

## 其他便利功能

背包、便携收纳、大背包和自己标记的箱子中的药水达到设置数量后，可提供持续增益，普通药水默认门槛为30瓶。增益站、旗帜和制作站也可随身生效；联机由服务器确认对应玩家的标记箱物品，不消耗用于激活的物品。标记箱子里的材料仍沿用原版合成核验。

- **红药水扩展**：无限红药水与红药水随处可用分别开关；数量门槛1—300瓶，默认20瓶。达到数量后，特殊种子世界或开启随处可用时持续提供18种增益：黑曜石皮、再生、敏捷、铁皮、魔力再生、魔能、羽落、洞穴探险、箭术、拾心、狩猎、耐力、生命力、地狱火、挖矿、暴怒、怒气和危险感知。随处可用还允许普通世界直接喝红药水获得原版正面增益；关闭后保留原版直接使用规则，不自动施加红药水的负面状态。
- **晶塔**：同类型晶塔放置数量豁免、传送无需靠近、无视危险环境、无视生物群系是四个独立开关，旧NPC数量豁免单独保留。放置仍需正常空间；Terraria 1.4.5.8原版已不检查传送时的战斗危险，该兼容开关在此版本不增加额外限制。
- **掉落与商店**：敌人钱币掉落倍率1—25，默认1；旗帜击杀要求1—500，默认50，保留真实击杀数和图鉴进度。开启旅商刷新后，在旅商商店点击“刷新旅商商店”，由服务器生成并同步货物。
- **重生加速**：“重生加速（非BOSS战）”与“重生加速（BOSS战）”独立控制，开启对应项后复活时间为90帧，正常速度约1.5秒。
- **禁止邪恶群落蔓延**：阻止腐化、猩红与神圣在自然世界更新中传播，保留玩家主动净化、喷溶液和世界生成。

模组设置还提供物品堆叠、自动存钱、工具速度与距离、回程道具使用加速、复活、睡觉加速、植物生长、住房、晶塔、NPC和图鉴等选项，可按需要开关。

## 联机与存档

联机支持自己标记的全世界箱子远程存取、合并和整理；操作由服务器核验，保留锁箱、占用、拆箱及不同前缀保护。普通箱子窗口与终极存储共用箱子占用规则，其他玩家正在使用的箱子不会被整理。

模组设置中的“将设置同步给房间内其他玩家”会发出申请，下方列表显示发起玩家、状态和“同意／拒绝”。个人设置由接收玩家自行同意；世界设置仅在房主／管理员同意后应用并广播，未应用的项目会说明原因。拒绝不会改动配置，离开房间后申请失效；不会同步快捷键、箱子标记、物品或存档。

大背包和箱子标记会在保存、退出世界时保存。备份时，请一并保留游戏存档目录下的 `TerrariaModder/player-data/` 和 `TerrariaModder/world-data/`。移动或重命名角色存档文件后，大背包可能无法对应到原数据。

存档损坏时会尝试恢复备份，无法恢复的大背包会暂停存取，避免覆盖原文件。退出世界后，功能窗口、自动钓鱼和结构扫描都会关闭，已保存的刷怪倍率保留。

联机存取断线后，会向原服务器查询未确认操作，在同一次服务器运行期间恢复库存。服务器重启后无法确认旧结果，或事务记录损坏时，会锁定相关库存并显示原因；请保留角色存档及 `player-data/`、`world-data/` 中的记录和 `.cursor` 文件，不要删除文件尝试解除锁定。普通鼠标物品记录也会在保存时核验，重新载入时按对应角色存档恢复。

程序集与行为回归用于检查协议和补丁，双客户端并发、断线重连、中文输入、旅商及晶塔等场景仍需游戏内验证；不将构建通过视为完整联机验收。开发构建和测试命令见 [BUILDING.md](BUILDING.md)。

### v1.0.0 · 2026-10-10

本版本已实现以下功能。可配置项目的实际效果以模组设置中的开关和数量门槛为准。

#### 收纳与物品整理

- **终极存储面板**：集中查看已标记箱子中的物品。打开普通箱子后自动标记，也可手动全部标记、取消标记或标记附近箱子。
- **分类浏览**：支持全部、武器、防具、饰品、工具、弹药、建筑、药水和家具分类；工具与弹药单独识别，不混入武器分类。
- **名称与前缀搜索**：可输入物品名称或前缀查找物品，支持中文输入、清空搜索和按钮翻页。
- **六种浏览顺序**：默认、种类、稀有度、数量、名称、ID。种类排列依次为武器、防具、饰品、工具、弹药、建筑、药水、家具、其他，同类按名称排列。
- **便捷存取**：左键取整组，右键取一半，拿着物品点击格子可存入；提供全部存入、快速堆叠、整理箱子和全部取出按钮，收藏物品不会被批量存入。
- **跨箱合并整理**：先把同一物品、同一前缀的堆叠合并到较早的箱子，再按所选规则整理各箱。达到堆叠上限后保留余量，不同前缀和不可堆叠装备保持分开。
- **箱子操作范围**：只整理已标记、未锁定、未被他人占用且可写的箱子。联机客户端的远程箱子可查看和参与合成，普通存取与整理限当前已确认打开的箱子。
- **100格随身大背包**：提供独立角色仓库，支持整组抓取、放入、交换，Shift＋左键快速取到角色背包，以及批量存入、取出和整理。
- **前缀与图标显示**：两个存储窗口的悬停名称显示完整前缀；图标保留物品自身颜色、动画和发光效果，使用物品实际属性绘制。
- **便携收纳快捷操作**：`.` 打开猪猪钱罐；开启对应选项后，可在背包里中键点击便携收纳道具，打开相应收纳。
- **物品堆叠与存钱**：可提高可堆叠物品上限至9999（金钱除外），并把拾取的钱币转入猪猪钱罐。
- **信息配件随身生效**：开启对应选项后，原版便携收纳中的信息配件也可提供其信息效果。
- **重铸词缀记录**：开启对应选项后记录重铸词缀历史，支持在重铸槽右键回到已记录的词缀。

#### 建造与液体工具

- **快速放置**：`P` 开关，手持方块、平台或背景墙，左键拖拽框选、松开铺设，右键取消。单格预览和拖拽范围适配视距与UI缩放。
- **快速铺墙**：`O` 使用背包中靠前的一组背景墙，填充角色周围没有墙的区域；背包没有墙时会提示。
- **建筑材料消耗开关**：快速放置和快速铺墙可独立选择是否消耗材料，和9999堆叠开关分开控制。
- **液体魔杖**：`L` 切换关闭、水、岩浆、微光、蜂蜜模式，按住 `;` 吸收、按住 `'` 放置。
- **液体数量与HUD**：按实际液体量记录，放置时补足格子缺少的量，满格不重复扣量；HUD显示当前模式和储量，可拖动位置。退出世界保留本次游戏的储量，退出游戏后不保留。
- **工具加速与距离**：可加快挖掘、斧锤使用、方块放置和铺墙，并单独开启额外工具触及距离。

#### 钓鱼与探索

- **自动钓鱼**：`Z` 开关，正常速度下约每10秒尝试一次。需要鱼竿、合适鱼饵和附近有效液体；手持鱼竿优先，否则选择背包中渔力最高的杆。
- **保留钓鱼规则**：按原版渔力、群落、任务鱼、鱼饵消耗、断线和钓出敌怪规则结算，不保证每次有渔获，不钓微光。
- **渔获自动收纳**：依次尝试25格内可写的标记箱子、角色背包和可保存的大背包，剩余物品掉在角色脚下。
- **任务鱼相关选项**：支持任务鱼堆叠、当天继续垂钓任务鱼，以及提交后刷新渔夫任务的便利选项。
- **结构定位**：`G` 面板支持以太微光湖、地牢、丛林神庙、世纪之花花苞、附魔剑冢、空岛、金字塔、蜂巢、大理石和花岗岩共10种目标。
- **扫描进度与地图点亮**：逐帧搜索并显示进度，找到后点亮附近地图；花苞和蜂巢幼虫可选择距离角色较近的目标。联机仅搜索客户端已加载的区域。
- **当前快捷键表**：结构面板显示实际改键后的绑定，悬停可查看功能说明。

#### 角色与战斗辅助

- **角色属性面板**：`Y` 查看各类伤害加成、暴击率、防御与免伤、护甲穿透、生命回复、移动速度、仆从与哨兵上限、基础钓鱼力。
- **测试假人**：`X` 在鼠标位置放置或移除独立测试假人，显示实时DPS、平均DPS、累计伤害和耗时；HUD可拖动，右键重置。
- **伤害记录区分**：同帧不同攻击分别统计，重复回调不会重复累加；假人保留原版无敌帧。
- **快捷护士治疗**：`H` 按模组治疗规则扣费，恢复生命与魔力，并清除可处理的负面状态。
- **回程道具加速**：可缩短魔镜、回忆药水、返回药水、海螺和贝壳手机等道具的等待，保留原本目的地和返回药水的回程点。
- **死亡与复活选项**：支持不生成墓碑、保存死亡前的正面增益、满生命与魔力复活，以及场上无Boss时约1.5秒快速复活。
- **消耗品便利选项**：支持弹药达到3996、坠落之星达到999后的免消耗，以及对应召唤道具、投掷消耗品、电线与促动器的免消耗选项；后几类中的数量条件以设置说明为准。
- **战斗与拾取选项**：可扩大拾取范围、关闭随机伤害浮动，并开启自身炸弹免伤；其他玩家炸弹和敌怪弹幕仍按原规则处理。
- **队内传送选项**：支持放宽虫洞药水的使用条件，并提供不消耗虫洞药水的选项。

#### 世界、植物与城镇NPC

- **刷怪率控制**：`[` 面板提供0、0.5、1、2、5、10、30倍预设，0为和平模式；联机客户端仅查看，由负责世界的一端控制。
- **节日与世界特性**：可切换万圣节、圣诞节，以及醉酒、天顶、颠倒、饥荒等世界运行特性；不会重新生成已有地形。
- **晴雨切换**：`U` 切换下雨和放晴。
- **睡觉与出生点选项**：可放宽睡觉限制、调整睡觉时间加速倍率，并放宽床设置出生点的房屋要求。
- **植物便利选项**：支持草药随时开花、再生法杖／再生之斧收割后补种、树苗生长与地下种树、生命果生成概率提升和南瓜生长加速；仍保留相应生长条件。
- **树木掉落选项**：支持摇树水果掉落和宝石树宝石掉落的便利设置。
- **环境保护选项**：可限制邪恶与神圣草地的自然蔓延，阻止非玩家爆炸物破坏物块，并阻止熔岩史莱姆死亡产生岩浆。
- **晶塔与提炼机**：可放宽晶塔传送的靠近和NPC数量条件，加快提炼机处理材料。
- **NPC回家与保护**：`N` 召回城镇NPC；提供NPC免伤、加快入住、满足条件后便利入住、邪恶环境住房和快乐度相关选项。
- **城镇与图鉴选项**：支持旅商留驻、发型师全部发型解锁，以及一次击杀后解锁对应图鉴资料。
- **后台运行**：可开启失焦后继续运行的选项。

#### 界面与保存

- **窗口位置适配**：分辨率或UI比例变化后校正窗口位置，小屏幕收紧格子、按钮和说明文字，减少重叠及越界。
- **退出世界清理**：退出时关闭功能窗口、工具HUD、自动钓鱼和结构扫描，主菜单不留下世界内窗口。
- **角色与世界数据分开保存**：大背包随角色保存，箱子标记随世界保存，同名角色或世界不会混用同一份记录。
- **保存备份与恢复**：保存保留备份，损坏时尝试恢复；无法恢复的大背包暂停存取，避免覆盖原文件。旧存档迁移后保留原文件。
- **启动兼容修复**：调整内部初始化入口，避免在游戏依赖就绪前误初始化导致启动失败。

### v1.1.0 · 2026-10-10

本版本扩展了联机存储和设置申请，补齐配置范围与世界功能。联机需要房主／专用服务器和所有玩家安装相同版本；完整的双客户端运行场景仍需游戏内验收。

#### 收纳与物品整理

- **全世界标记箱远程存取**：自己标记的箱子无需靠近或先打开即可查看、取出、存入、快速堆叠和跨箱整理，由服务器核验后执行。不同前缀保持分开，锁定、被他人占用或已拆除的箱子不能操作。
- **箱子管理原版打开入口**：点击箱子管理中的“打开”，请求打开对应箱子的原版窗口；保留原版箱子占用保护。
- **个人箱子标记**：服务器按玩家身份确认和保存标记，单机继续读取已有记录；不同玩家的便携增益与制作站使用各自标记箱，不再错误共用标记。
- **断线库存恢复**：记录未确认的物品交易，重连原服务器时查询结果，同一次服务器运行期间可恢复库存。服务器重启后旧结果不明或记录损坏时保持锁定，请保留角色存档、player-data、world-data及.cursor记录。
- **鼠标物品保存**：普通鼠标物品与对应角色存档核验保存，重新载入时恢复；记录不一致时保留文件并显示原因。

#### 建造与液体工具

- **可调放置与工具距离**：增加量改为0—30格整数，默认5格；0不扩展，同时作用于放置与工具。旧开／关配置迁移为5／0格。
- **服务器建筑操作**：联机快速放置与铺墙由服务器检查材料并修改世界，快速放置单次框选最多4096格，超过时缩小范围后重试。
- **个人液体储量**：联机吸放由服务器确认，储量按玩家保存在当前服务器世界会话；单机仍在本次游戏进程内保留储量。

#### 钓鱼与探索

- **服务器全世界结构扫描**：联机定位由服务器按帧预算搜索，找到后同步目标附近区块，不依赖客户端事先加载远处瓦片；退出或失效请求不再继续更新面板。
- **联机渔获收纳边界**：自动钓鱼继续使用客户端原版收获流程，新渔获不直接写入远程箱子；背包中的渔获可手动存入终极存储。单机保留附近箱子、背包和大背包的收纳顺序。

#### 角色与战斗辅助

- **护士按实际治疗收费**：快捷治疗及护士对话按缺失生命和原版可清除负面状态计算费用；满血且有可清除状态仍可收费治疗，完全无需治疗时提示且不扣钱，不因永久或不可清除状态空扣钱。
- **BOSS与非BOSS重生开关**：新增“重生加速（BOSS战）”，原开关改名为“重生加速（非BOSS战）”；各自开启时对应战斗状态下的复活时间为90帧，正常速度约1.5秒。
- **联机测试假人与个人DPS**：假人由服务器生成和移除，伤害记录只统计玩家自己对自己假人的命中，保留同帧合法攻击与重复回调去重，不清空原版无敌帧。
- **无限红药水扩展**：新增无限红药水和随处可用两个独立开关，需求量1—300瓶，默认20瓶。特殊种子世界或随处可用开启时，达到数量提供黑曜石皮、再生、敏捷、铁皮、魔力再生、魔能、羽落、洞穴探险、箭术、拾心、狩猎、耐力、生命力、地狱火、挖矿、暴怒、怒气及危险感知18种增益；普通世界直接使用受随处可用开关控制。
- **个人便携增益与制作站**：背包、便携收纳、大背包及对应玩家的有效标记箱物品提供增益、旗帜与制作站效果，不消耗用于激活的物品；服务器使用玩家确认的个人配置。

#### 世界、植物与城镇NPC

- **独立晶塔限制**：同类型晶塔放置数量、传送靠近玩家、危险环境和生物群系分别设置，旧NPC数量豁免继续保留。Terraria 1.4.5.8原版已不检查战斗危险，危险开关在此版本保留兼容说明。
- **自然感染蔓延补齐**：阻止腐化、猩红与神圣在自然世界更新中传播，保留玩家主动净化、喷溶液和世界生成；联机由服务器执行。
- **敌人钱币倍率**：新增1—25倍设置，默认1，在服务器实际掉落时计算一次，不反复修改敌怪基础价值。
- **旗帜击杀要求**：新增1—500次设置，默认50，按实际击杀间隔增加原版可领取旗帜；不改真实击杀统计或图鉴进度。
- **旅商商店刷新**：开启后在旅商商店显示“刷新旅商商店”，服务器生成并同步新货物。
- **0—100刷怪滑条**：保留原有档位，并在下方新增自由拖动滑条，松开后提交和保存倍率；0为和平模式，联机仅房主／管理员可以调整，无权限时说明原因。

#### 界面与保存

- **设置同步申请**：模组设置增加“将设置同步给房间内其他玩家”，下方申请列表显示发起玩家、状态及同意／拒绝，长列表可滚动。申请只包含本模组设置快照，不包含快捷键、箱子标记、物品或存档。
- **个人与世界配置区分**：个人项逐人同意后保存，世界项仅由房主／管理员同意后修改并广播；拒绝不改配置，未应用项目说明原因，玩家离开或世界会话结束后申请失效。
- **世界配置持久保存**：单机保存共享世界选项；服务器保存核验成功后广播，失败时回滚。退出世界不再清空已保存的刷怪倍率。
- **输入与会话清理**：新增按钮、滑条和申请列表消费鼠标输入，避免点击穿透；返回菜单、断线或卸载后清理窗口与待处理请求。
