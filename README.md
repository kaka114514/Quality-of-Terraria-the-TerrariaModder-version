# Quality of Terraria 更好的体验

基于[更好的体验(ImproveGame)](https://github.com/487666123/ImproveGame)的泰拉瑞亚模组。

**移植版本**：适配 TerrariaModder v0.4.1+  
**原版作者**：487666123  
**当前版本**：v1.2.5<br>
**适配游戏版本**：泰拉瑞亚 1.4.5.8+

v1.2.5 修复联机时部分功能开关、配置应用及药水黑名单不生效，以及掉落和生长逻辑重复执行的问题。房主／服务器和所有玩家都需更新至同一版本。

## 📖 简介

基于 tModLoader 平台热门 MOD [更好的体验(ImproveGame)](https://github.com/487666123/ImproveGame) 移植到 TerrariaModder 平台的版本。提供大量便捷功能，让玩家能够更流畅地享受游戏，而不改变核心玩法。

**核心特性**：

* 🎒 **强大的存储系统**：终极存储面板、100格随身大背包、智能物品整理
* 🔨 **便捷的建造工具**：快速放置、液体魔杖、连锁挖矿、挖掘加速
* 🗺️ **实用的辅助功能**：结构定位、自动钓鱼、NPC管理、护士快捷治疗
* 📊 **详细的信息面板**：角色属性、DPS测试、刷怪率控制
* 🌐 **联机存储**：普通玩家可用、角色标记独立保存、服务器核验存取

世界和服务器作用域的功能设置统一显示在模组设置页的“客户端”标签；多人游戏中的保存、权限核验和实际执行仍由房主／服务器负责。

设置页支持本机配置档案：内置“默认”和“上一次”两个不可删除档案；应用配置或发起／接收设置同步前会自动保存当前设置到“上一次”。右侧 `+` 可保存自定义档案，选中后可应用、重命名或删除。

<summary><b>🎒 收纳与物品整理</b></summary>

### 终极存储面板 (K)

* 集中查看已标记箱子中的所有物品
* 打开普通箱子会自动标记，也可在终极存储的箱子管理页取消标记
* 联机标记按“世界＋角色”独立保存，其他玩家增删标记不会影响自己；重新进房或服务器重启后恢复
* 普通玩家也可远程使用自己的标记箱子，无需房主或管理员权限；箱子管理中的“打开”可打开对应原版箱子窗口
* 六种排序方式：默认、种类、稀有度、数量、名称、ID
* 原版旅行模式分类：全部、武器、盔甲、时装、物块、家具、配饰、装备、消耗品、工具、材料、其他
* 分类按钮分两行显示；物品生成器、大背包和终极存储遵循同一套原版规则，允许物品出现在多个适用分类，例如铜短剑同时属于武器和材料。物块、家具不会混入消耗品筛选，工具包含扳手、桶等原版特殊工具。
* 名称与前缀搜索，支持中文输入
* 左键取整组，右键取一半，拿着物品点击可存入
* 跨箱智能合并与整理：同物品同前缀自动合并，支持多种整理规则
* 库存操作等待确认时，可先用“重试核验”重新查询结果；仍无法恢复时可使用“强制解锁”，再次点击确认后放弃当前等待。强制解锁不会等待旧请求返回，请优先尝试重试核验。



### 100格随身大背包 (B)

* 独立角色仓库，不占用背包空间
* 支持整组抓取、快速放入、Shift+左键快速取出
* 提供批量存入、取出、整理功能
* 完整显示前缀与物品属性
* 分类统一为：全部、武器、盔甲、时装、物块、家具、配饰、装备、消耗品、工具、材料、其他

### 物品生成器（T）

* 在设置页打开独立的物品生成器窗口；若要使用 `T` 快捷键，先开启“启用物品生成器快捷键”，该开关默认关闭。
* `G` 键快捷键表会显示物品生成器快捷键的开关状态。
* 按图标网格浏览物品，鼠标悬停显示名称；支持名称搜索、分类、分页和数量输入，单次数量为1～9999。
* 分类与大背包、终极存储一致，采用原版旅行模式的11类及“全部”；按钮分两行排列在搜索与数量栏下方。
* 点击物品图标后加入背包，空间不足时会提示；关闭按钮可直接关闭窗口。
* 单人模式可直接使用；多人生成物品需要房主或管理员权限，由服务器执行并同步物品栏。

### 便携收纳增强

* 按 `.` 打开选择面板，可选猪猪钱罐、保险箱、护卫熔炉和虚空袋；选择后使用原版收纳窗口，再按 `.` 或关闭背包可关闭
* 已移除中键打开便携收纳入口；远离实体钱罐或箱子时，快捷打开的收纳窗口也能保持开启
* 联机从世界箱子切换到快捷收纳时会释放原箱子占用，其他玩家可继续使用
* 开启“便携收纳信息配件生效”后，玩家背包、四种便携收纳和自己标记的全世界箱子中的信息配件均可生效
* 拾取的金钱自动存入猪猪钱罐

### 重铸词缀记录

* 记录重铸历史词缀
* 右键点击重铸槽可回到之前的词缀
* 避免误操作丢失心仪词缀

### 快速工具（P）

* 按 `P` 循环切换：关闭 → 快速放置 → 破坏 → 复制 → 粘贴 → 关闭；切换提示中会提醒 `Ctrl+P` 可打开配置页。
* **快速放置**：手持方块、平台或背景墙，左键拖拽框选，松开后铺设；单次选区最多4096格。右键可取消当前框选。
* 草种等种植物品遵守原版种植规则，不会强行替换已有方块；打开全屏地图会自动关闭快速放置。
* 是否替换已有地形、是否消耗快速放置材料，在 `Ctrl+P` 中分别设置。四种快速工具模式开启时会暂时拦截手持物品的世界交互，避免攻击、挖掘、放置、投掷或消耗物品；背包、原版设置和模组窗口仍可正常点击，按 `P` 切换到“关闭”后恢复物品使用。
* 切换模式或关闭快速工具时，先松开当前按住的左右键，再开始下一次操作；切换时会结束当前手持物品的持续使用，防止同一次按住鼠标变成原版攻击。
* **破坏模式**：左键框选要清理的区域；按背包内镐子与锤子的原版能力处理方块和背景墙，无法破坏的内容跳过，并提示已破坏、跳过的数量。
* 背景墙是否破坏、破坏是否产生掉落物品均可单独控制；开启掉落时，方块和墙按原版规则产生掉落。
* 多人模式中的区域放置、破坏与结构粘贴由服务器核验并执行。

### 结构剪贴板（Ctrl+P）

* **复制**：先按 `P` 切换到复制模式，再左键框选结构。结构保存在本机，最多100个，单个结构最多10000格，可跨世界、跨角色使用。
* `Ctrl+P` 打开结构库与快速工具配置页。已保存结构以图片卡片展示，支持名称搜索、重命名、删除；鼠标悬停结构图片可查看材料需求。
* 点击“应用”只选中对应结构，不会立即粘贴。切换到粘贴模式后，鼠标处显示半透明投影，左键才会放置结构；没有选中结构时只提示一次。
* 退出粘贴模式后投影消失。投影与实际放置共用坐标，缩略图按完整结构范围居中显示。
* 保存并粘贴方块、背景墙及其帧、颜色、斜坡、半砖、电线、致动器等状态；不保存箱子内容和独立实体数据。
* 墙体预览保留完整边缘，树木分别显示树干、树冠和树枝；大结构不跳格抽样。新复制的结构会记录树种外观，旧结构仍可读取，重新复制可补齐原树种信息。

配置页中的选项分别控制各自模式：

|选项|默认状态|作用|
|-|:-:|-|
|粘贴消耗材料|开启|粘贴时扣除背包中的所需材料|
|粘贴破坏地形|关闭|允许粘贴前清理目标位置的已有方块|
|快速放置破坏地形|关闭|允许快速放置替换目标位置的已有方块|
|快速放置不消耗|关闭|快速放置时不消耗背包材料|
|破坏背景墙|开启|破坏模式同时处理选区内的背景墙|
|破坏掉落物|开启|破坏模式产生方块、墙的掉落物品；关闭后不产生掉落|

### 液体魔杖 (L)

* 按 `L` 循环切换：关闭 → 水 → 岩浆 → 微光 → 蜂蜜
* 按住 `;` 吸收鼠标处液体
* 按住 `'` 放置已吸收的液体
* 无需携带水桶，随时随地操作液体

### 连锁挖矿 (V)

* 一键开启/关闭矿石连锁挖掘
* 按住 `Shift` 临时强制连锁，松开恢复原状态
* “提炼物可连锁”位于连锁挖矿开关下方，默认关闭；开启后支持泥沙块、雪泥块和沙漠化石，需开启连锁挖矿或按住强制连锁键。
* 三类提炼物始终只连锁相同种类，沿用连锁范围、数量上限、镐力检查和自动入包设置；正常掉落原方块，不会自动提炼。多人游戏由服务器核验并执行。
* 大幅提升矿石采集效率

### 挖掘加速 (\\)

* “挖掘加速”统一控制镐、斧和锤；“放置加速”独立控制方块与背景墙
* 挖掘加速范围为1.0～4.0倍，放置加速范围为1.0～2.5倍；两项均可拖动滑条或点击数值输入后按回车确认，步长0.1，1.0为原版速度
* `\` 暂停／恢复挖掘和放置加速，不改变已设置的倍率。旧配置沿用挖掘倍率作为合并值，放置级别换算为原有效倍率

## 🌐 联机支持

房主／服务器和所有玩家安装相同修复版后，可使用联机功能。

### 服务器部署

* 将发布包中的 `quality-of-terraria` 文件夹放入 `TerrariaModder/mods/`，更新时覆盖同名文件
* 服务器目录中需同时包含 `QualityOfTerraria.dll`、`QualityOfTerraria.Server.bin` 和 `manifest.json`
* 所有玩家也需更新同一份安装包，然后重启游戏及服务器；服务器不会自动替玩家安装模组

### 权限管理

* **刷怪率控制**：仅房主或管理员可提交修改
* **世界特性调整**：仅房主或管理员可修改
* **物品生成器**：多人模式下仅房主或管理员可生成物品
* **终极存储与个人功能**：普通玩家可使用自己的标记箱子及个人设置；涉及世界改动的操作由服务器核验

### 数据同步

* 终极存储标记各角色独立，随身大背包随角色保存；两名玩家可以分别标记同一个世界箱子，箱内实物仍是同一份
* 终极存储读取自己标记且经服务器确认的箱子；锁定、被其他玩家占用的箱子不能操作
* 每个角色拥有独立标记列表，角色在游戏内改名后仍保留。首次升级会复制服务器上旧身份的标记，之后各自增删；旧文件保留
* 房主／服务器与所有玩家都需更新至 v1.2.5，避免版本和设置同步不兼容
* 世界和服务器作用域的设置统一显示在“客户端”设置栏；联机时仍由房主／服务器保存、校验和执行
* 同一个角色连同 ID 文件复制后的副本属于同一角色，会使用同一份标记；新建角色拥有独立身份

## 💾 存档备份建议

使用本模组时，强烈建议定期备份存档：

1. **角色存档路径**（Windows）：

```
   C:\\Users\\<用户名>\\Documents\\My Games\\Terraria\\Players\\
   ```

2. **世界存档路径**（Windows）：

```
   C:\\Users\\<用户名>\\Documents\\My Games\\Terraria\\Worlds\\
   ```

3. **建议**：

   * 在使用新模组功能前备份一次
   * 定期（如每周）备份重要存档
   * 大型建设或重要战斗前备份
   * 角色存档旁的 `角色文件名.plr.qot-character-id` 保存终极存储角色身份。换电脑或手动移动／重命名存档时，连同此文件一起迁移，并与 `.plr` 文件名保持对应
   * 服务器标记保存在游戏存档目录的 `TerrariaModder/world-data/` 下；迁移服务器时连同世界一起备份。删除角色 ID 或服务器标记文件会使原标记无法对应

**原版／模组版切换兼容（v1.1.5）**：如果角色在原版中重新保存，模组会在没有待恢复交易时，核对当前背包和鼠标物品是否与原版存档一致。核验通过后正常使用，旧鼠标记录和当前角色文件会备份在 `TerrariaModder/player-data/` 下的 `.cursor.stale-*` 文件中。若仍提示无法核验，请保留角色及模组记录，不要删除事务或鼠标文件来解除锁定。
