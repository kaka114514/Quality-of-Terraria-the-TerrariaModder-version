## 📖 简介

基于 tModLoader 平台热门 MOD [更好的体验(ImproveGame)](https://github.com/487666123/ImproveGame) 移植到 TerrariaModder 平台的版本。提供大量便捷功能，让玩家能够更流畅地享受游戏，而不改变核心玩法。

**核心特性**：

* 🎒 **强大的存储系统**：终极存储面板、100格随身大背包、智能物品整理
* 🔨 **便捷的建造工具**：快速放置、液体魔杖、连锁挖矿、工具加速
* 🗺️ **实用的辅助功能**：结构定位、自动钓鱼、NPC管理、护士快捷治疗
* 📊 **详细的信息面板**：角色属性、DPS测试、刷怪率控制
* 🌐 **联机存储**：普通玩家可用、角色标记独立保存、服务器核验存取

## ⚡ 核心功能

<details>
<summary><b>🎒 收纳与物品整理</b></summary>

### 终极存储面板 (K)

* 集中查看已标记箱子中的所有物品
* 打开普通箱子会自动标记，也可在终极存储的箱子管理页取消标记
* 联机标记按“世界＋角色”独立保存，其他玩家增删标记不会影响自己；重新进房或服务器重启后恢复
* 普通玩家也可远程使用自己的标记箱子，无需房主或管理员权限；箱子管理中的“打开”可打开对应原版箱子窗口
* 六种排序方式：默认、种类、稀有度、数量、名称、ID
* 九大分类浏览：全部、武器、防具、饰品、工具、弹药、建筑、药水、家具
* 名称与前缀搜索，支持中文输入
* 左键取整组，右键取一半，拿着物品点击可存入
* 跨箱智能合并与整理：同物品同前缀自动合并，支持多种整理规则

### 100格随身大背包 (B)

* 独立角色仓库，不占用背包空间
* 支持整组抓取、快速放入、Shift+左键快速取出
* 提供批量存入、取出、整理功能
* 完整显示前缀与物品属性

### 便携收纳增强

* 按 `.` 打开选择面板，可选猪猪钱罐、保险箱、护卫熔炉和虚空袋；选择后使用原版收纳窗口，再按 `.` 或关闭背包可关闭
* 已移除中键打开便携收纳入口；远离实体钱罐或箱子时，快捷打开的收纳窗口也能保持开启
* 联机从世界箱子切换到快捷收纳时会释放原箱子占用，其他玩家可继续使用
* 开启“便携收纳信息配件生效”后，玩家背包、四种便携收纳和自己标记的全世界箱子中的信息配件均可生效
* 拾取的金钱自动存入猪猪钱罐

### 重铸词缀记录

* 记录重铸历史词缀
* 右键点击重铸槽可回到之前的词缀
* 避免误操作丢失心仪词缀

</details>

<details>
<summary><b>🔨 建造与液体工具</b></summary>

### 快速放置 (P)

* 手持方块、平台或墙壁时，左键拖拽快速铺设
* 草种等种植物品遵守原版规则，不会替换已有方块；框选上限为4096格
* 打开全屏地图时自动关闭，避免误铺
* 右键取消最后一次放置
* 大幅提升建筑效率

### 液体魔杖 (L)

* 按 `L` 循环切换：关闭 → 水 → 岩浆 → 微光 → 蜂蜜
* 按住 `;` 吸收鼠标处液体
* 按住 `'` 放置已吸收的液体
* 无需携带水桶，随时随地操作液体

### 连锁挖矿 (V)

* 一键开启/关闭矿石连锁挖掘
* 按住 `Shift` 临时强制连锁，松开恢复原状态
* 大幅提升矿石采集效率

### 工具加速 (\\)

* “挖掘与伐木加速”统一控制镐、斧和锤；“放置加速”独立控制方块与背景墙
* 两项倍率都可拖动滑条，或点击右侧数值输入后按回车确认；范围1.0～4.0倍，步长0.1，1.0为原版速度
* `\` 暂停／恢复两项加速，不改变已设置的倍率。旧配置沿用挖掘倍率作为合并值，放置级别换算为原有效倍率

</details>

### 结构定位 (G)

* 点击结构图标直接标记并点亮地图迷雾

### 自动钓鱼 (Z)

* 背包有鱼竿和鱼饵时可用
* 在液体附近自动每10秒尝试钓鱼
* 使用原版钓鱼机制结算
* 解放双手，轻松钓鱼

### 城镇NPC管理 (N)

* 一键将所有城镇NPC召回各自房间
* 快速整理NPC位置
* 避免NPC走失

### 快捷护士治疗 (H)

* 无需对话，一键瞬间回满血与魔力
* 清除所有Debuff
* 按原版价格收费
* 战斗间隙快速恢复

<details>
<summary><b>📊 信息与测试工具</b></summary>

### 角色属性面板 (Y)

* 实时显示当前角色的完整属性
* 攻击力、防御力、暴击率、穿透等
* 移动速度、跳跃高度、生命/魔力再生
* 方便对比装备与配件效果

### 测试假人 (X)

* 在鼠标位置放置或移除测试假人
* 实时统计DPS输出
* 测试武器与Build效果的利器

### 世界控制 (\[)

* 敌对生物和兔子、鸟、蝴蝶等小动物倍率独立调节，各为0～500倍，默认1倍；城镇NPC不受影响
* “刷怪与时间”页可拖动00:00～23:59时间条，点击右侧“应用”后生效；拖动时只预览
* “节日与事件”页切换万圣节、圣诞节；每次进入世界默认关闭万圣节，可手动开启
* 可开始／结束血月、日食、南瓜月和霜月。日食需白天，其余需夜晚；不满足时会提示先调整时间。结束事件不会清除已经生成的敌怪
* “世界特性”页保留醉酒、天顶、颠倒和饥荒机制切换，不重新生成地形
* 联机模式需房主/管理员权限提交

### 天气控制 (U)

* 关闭该开关后需使用附近实体制作站，但标记箱材料仍可远程使用；保留配方、材料数量、群落等原有条件

### 金币自动存入猪猪钱罐

* 背包更整洁

## 🌐 联机支持

房主／服务器和所有玩家安装相同修复版后，可使用联机功能。

### 服务器部署

* 将发布包中的 `quality-of-terraria` 文件夹放入 `TerrariaModder/mods/`，更新时覆盖同名文件
* 服务器目录中需同时包含 `QualityOfTerraria.dll`、`QualityOfTerraria.Server.bin` 和 `manifest.json`
* 所有玩家也需更新同一份安装包，然后重启游戏及服务器；服务器不会自动替玩家安装模组

### 权限管理

* **刷怪率控制**：仅房主或管理员可提交修改
* **世界特性调整**：仅房主或管理员可修改
* **其他功能**：所有玩家均可独立使用

### 数据同步

* 终极存储标记各角色独立，随身大背包随角色保存；两名玩家可以分别标记同一个世界箱子，箱内实物仍是同一份
* 终极存储读取自己标记且经服务器确认的箱子；锁定、被其他玩家占用的箱子不能操作
* 每个角色拥有独立标记列表，角色在游戏内改名后仍保留。首次升级会复制服务器上旧身份的标记，之后各自增删；旧文件保留
* 房主／服务器与所有玩家都需更新至 v1.1.6，避免版本和设置同步不兼容
* 同一个角色连同 ID 文件复制后的副本属于同一角色，会使用同一份标记；新建角色拥有独立身份

## 💾 存档备份建议

使用本模组时，强烈建议定期备份存档：

1. **角色存档路径**（Windows）：

```
   C:\\Users\\<用户名>\\Documents\\My Games\\Terraria\\Players\\
   ```

2. **世界存档路径**（Windows）：

```
   C:\\Users\\<用户名>\\Documents\\My Games\\Terraria\\Worlds\\
   ```

3. **建议**：

   * 在使用新模组功能前备份一次
   * 定期（如每周）备份重要存档
   * 大型建设或重要战斗前备份
   * 角色存档旁的 `角色文件名.plr.qot-character-id` 保存终极存储角色身份。换电脑或手动移动／重命名存档时，连同此文件一起迁移，并与 `.plr` 文件名保持对应
   * 服务器标记保存在游戏存档目录的 `TerrariaModder/world-data/` 下；迁移服务器时连同世界一起备份。删除角色 ID 或服务器标记文件会使原标记无法对应

**原版／模组版切换兼容（v1.1.5）**：如果角色在原版中重新保存，模组会在没有待恢复交易时，核对当前背包和鼠标物品是否与原版存档一致。核验通过后正常使用，旧鼠标记录和当前角色文件会备份在 `TerrariaModder/player-data/` 下的 `.cursor.stale-*` 文件中。若仍提示无法核验，请保留角色及模组记录，不要删除事务或鼠标文件来解除锁定。
